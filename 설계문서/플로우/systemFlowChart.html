🩺 전체 시스템 동작 흐름도

Surearly Multi 진단기 — 전원을 넣은 후부터 결과가 나올 때까지의 큰 그림입니다.
각 단계의 세부 동작(내부 판정 기준 등)은 별도 문서에서 다룹니다.

대기/절전 상태 정상 진행 단계 결과 출력 오류(문제 발생) 처리 정상 완료 후 복귀 시간 초과(오류 아님) 오류 발생 경로

🔎 단계별 자세히 보기

1
😴 대기 모드 (절전)
시간 제한 없음

평소에는 배터리를 아끼기 위해 이 상태로 계속 잠들어 있습니다. 스틱이 꽂히는 순간에만 깨어납니다.

2
🔍 스틱 확인 & 초기 점검
몇 초

깨어나서 스틱이 실제로 꽂혔는지 다시 한번 확인하고, 사용 횟수·스틱 상태·센서 밝기를 점검/보정합니다.

⚠ 사용 횟수 초과 / 스틱 불량 / 스틱 빠짐 → 오류 처리로
3
💧 샘플(소변) 투입 대기
최대 5분

스틱에 샘플이 투입되는 것을 계속 지켜봅니다. 샘플이 감지되면 바로 다음 단계로 넘어갑니다.

⏱ 5분 안에 샘플이 감지되지 않으면, 오류 표시 없이 조용히 대기 모드로 돌아갑니다
4
⚗️ 샘플량 확인 & 반응 대기
총 3분

투입 직후 샘플이 너무 많거나(과다) 너무 적지(부족) 않은지 먼저 확인한 뒤, 남은 시간 동안 화학 반응이 끝나기를 기다립니다.

⚠ 샘플 과다 / 샘플 부족 / 중간에 스틱 빠짐 → 오류 처리로
5
📊 최종 측정 & 판독
몇 초

시험선과 대조선의 밝기를 측정해 양성/음성을 판정합니다. 대조선이 제대로 나오지 않으면 검사 자체가 무효로 처리됩니다.

⚠ 대조선(정상 판정 기준선) 이상 → 오류 처리로
6
✅ 결과 표시
약 5분간 표시

양성(YES)/음성(NO) 결과를 화면에 보여주고, 측정값을 기기 내부(EEPROM)에 기록한 뒤 다시 대기 모드로 돌아갑니다.

!
🚫 오류(문제) 처리 — 공통
약 2분간 표시

2~5번 중 어느 단계에서 문제가 생기든 처리 방식은 동일합니다.
① 무엇이 잘못됐는지 기기 내부(EEPROM)에 기록 → ② 화면에 오류 메시지 표시(약 2분) → ③ 대기 모드로 복귀

↩ 처리가 끝나면 1번 "대기 모드"로 돌아갑니다
Surearly Multi / MFx_New_Ver — 전체 흐름 요약본 (비전공자용). 각 단계의 세부 판정 로직은 별도 문서 참고.
