# Work Log - 2026-06-16

## PC1 (PTR_PW) GPIO High 출력 불가 원인 분석

### 현상

`DM_HW_Drv_GPIO_Init()` 에서 아래와 같이 PC1을 Push-Pull High로 초기화하고 `DM_HW_Drv_PTR_Power_On()`을 호출해도 High 출력이 나오지 않음.

```c
/* USER/Drive/DM_HW_Drv.c - DM_HW_Drv_GPIO_Init() */
GPIO_Init(PTR_PW_PORT, PTR_PW_GPIO, GPIO_Mode_Out_PP_High_Slow);
DM_HW_Drv_PTR_Power_On();  // GPIO_SetBits(PTR_PW_PORT, PTR_PW_GPIO)

/* 핀 정의 */
// PTR_PW_PORT = GPIOC
// PTR_PW_GPIO = GPIO_Pin_1
```

---

### 원인: PC1 = True Open Drain 전용 핀

STM8L151F3 데이터시트 **Table 4 (p.28)** PC1 항목:

| 핀 | I/O Level | High sink/source | OD | PP |
|---|---|---|---|---|
| **PC1/I2C_SCL** | **FT** | ❌ 없음 | ✅ X (note 5) | ❌ 없음 |

> **Note 5**: *"T defines a true open-drain I/O — P-buffer(PMOS)와 VDD 보호 다이오드가 구현되어 있지 않음"*

**PC1은 실리콘 내부에 PMOS 트랜지스터가 물리적으로 존재하지 않는다.**  
Push-Pull 출력 구조 자체가 없으므로 소프트웨어로 아무리 High를 설정해도 전류를 Source할 수 없다.

#### 동작 메커니즘

```
GPIO_Mode_Out_PP_High_Slow 설정
        ↓
소프트웨어 레지스터 → High 기록 (레지스터 쓰기는 성공)
        ↓
하드웨어: PMOS가 없으므로 라인 Pull-High 불가
        ↓
High 상태 = 핀이 Floating (High-Z) 상태 → 출력 없음
```

- **Low 출력**: 내부 NMOS로 VSS 방향 Sink 가능 → 정상 동작
- **High 출력**: PMOS 없음 → Source 전류 0 → 핀 부유(Floating)

---

### 출력 전류 비교 (데이터시트 Table 38, 39)

| 핀 타입 | Source 전류 (High 출력) | Sink 전류 (Low 출력) |
|---|---|---|
| High Sink 포트 (PA, PB, PD 등) | 최대 10 mA (VOH ≥ VDD-0.7V) | 최대 10 mA |
| **PC0, PC1 (True Open Drain)** | **0 mA — 불가** | 최대 3 mA (VDD=3.0V) |

> **Table 36 (p.79)**: "Injected current on true open-drain pins (**PC0 and PC1**)" 로 별도 분류됨.  
> PC0/PC1은 I2C(SDA/SCL) 전용으로 설계된 True OD 구조이며, PTR 전원 제어 용도로 사용 불가.

---

### 해결 방법

#### 방법 1: 외부 Pull-up 저항 추가 (하드웨어 수정)

```
VDD ──[ 10kΩ ]── PC1 (PTR_PW) ── 부하
```

- High 설정 시: 핀 High-Z → 저항이 VDD로 Pull-up → 정상 High
- Low 설정 시: 내부 NMOS가 VSS로 당김 → 정상 Low
- 출력 전류: 풀업 저항값으로 결정 (10kΩ 기준 약 0.33 mA @ 3.3V)
- **단점**: 부품 추가 필요, 전류 공급 능력이 매우 낮음

#### 방법 2: GPIO 핀 변경 (소프트웨어 수정 — 권장)

PTR_PW 신호를 Push-Pull 지원 핀으로 이동.

지원 핀: **PB, PD, PE, PC2~PC6** 등 (Table 4에서 PP = X 인 핀)

```c
/* 변경 전 (잘못된 핀) */
#define PTR_PW_PORT    GPIOC
#define PTR_PW_GPIO    GPIO_Pin_1   // True OD → Push-Pull 불가

/* 변경 후 (예시: 실제 회로에 맞게 선택) */
#define PTR_PW_PORT    GPIOD
#define PTR_PW_GPIO    GPIO_Pin_0   // High Sink/Source 지원, 최대 10 mA
```

- 추가 부품 없이 코드 변경만으로 해결
- Source/Sink 전류 최대 10 mA 확보 (VOH ≥ VDD-0.7V @ 10 mA, VDD=3.0V)

### 참고: PC0/PC1 사용 가능한 용도

| 기능 | 가능 여부 |
|---|---|
| I2C SDA/SCL | ✅ (Open Drain 특성 필요) |

| GPIO Low 출력 | ✅ 가능 (Sink 최대 3 mA) |
| Push-Pull 전원 제어 | ❌ 핀 변경 필요 |

## LCD GPIO 핀 검토

### 핀 정의

```c
/* Custom LCD */
#define LCD_COM0_GPIO_PORT    GPIOC
#define LCD_SEG0_GPIO_PORT    GPIOC
#define LCD_SEG1_GPIO_PORT    GPIOC
#define LCD_SEG2_GPIO_PORT    GPIOD
#define LCD_SEG3_GPIO_PORT    GPIOB

#define LCD_COM0_GPIO_PIN     GPIO_Pin_0
#define LCD_SEG0_GPIO_PIN     GPIO_Pin_5
#define LCD_SEG1_GPIO_PIN     GPIO_Pin_6
#define LCD_SEG2_GPIO_PIN     GPIO_Pin_0
#define LCD_SEG3_GPIO_PIN     GPIO_Pin_0
```

### 검토 결과 (Table 4 기준)

| 신호 | PORT | PIN | 실제 핀 | I/O Level | PP 출력 | 판정 |
|---|---|---|---|---|---|---|
| **LCD_COM0** | GPIOC | Pin_0 | **PC0** | FT | ❌ True OD | **문제** |
| LCD_SEG0 | GPIOC | Pin_5 | PC5 | HS | ✅ PP 지원 | 정상 |
| LCD_SEG1 | GPIOC | Pin_6 | PC6 | HS | ✅ PP 지원 | 정상 |
| LCD_SEG2 | GPIOD | Pin_0 | PD0 | HS | ✅ PP 지원 | 정상 |
| LCD_SEG3 | GPIOB | Pin_0 | PB0 | HS | ✅ PP 지원 | 정상 |

**문제 핀은 LCD_COM0 (PC0) 단 하나. SEG 핀 4개는 모두 정상.**

### LCD_COM0 동작 영향 분석

**Case 1 — COM0를 항상 Low로만 유지하는 경우 (Static LCD)**
```
COM0 = 항상 Low (NMOS 동작) → True OD여도 문제없음 ✅
SEG 라인만 High/Low 전환하여 세그먼트 제어
```

**Case 2 — COM0를 High/Low 교번 구동하는 경우 (AC 구동)**
```
COM0 High 설정 시 → Floating (High-Z) → LCD에 DC 성분 발생
DC 성분은 LCD 패널 수명 단축 및 표시 불량 원인 ❌
```

현재 `DM_HW_Drv_Power_PrepareSleep()` (line 491)에서 COM0 Reset이 주석 처리되어 있어
**COM0는 Low 고정 운용**으로 판단 → 현재 동작에는 실사용 무방.

```c
/* DM_HW_Drv.c line 491 */
//GPIO_ResetBits(LCD_COM0_GPIO_PORT, LCD_COM0_GPIO_PIN); // 주석 처리됨
```

### 결론

| 항목 | 내용 |
|---|---|
| 문제 핀 | PC0 (LCD_COM0) — True Open Drain |
| SEG 핀 4개 | 모두 정상 (HS Push-Pull 지원) |
| 현재 운용 방식 | COM0 Low 고정이라면 실사용 무방 |
| 리스크 | COM0 High 구동 필요 시 외부 Pull-up 추가 또는 PD/PB 계열 핀으로 변경 필요 |

## STP_CK / PTR_PW 핀 검토

### 핀 정의

```c
/* Strip Check */
#define STP_CK_PORT    GPIOB
#define STP_CK_PIN     GPIO_Pin_1

/* PTR Power */
#define PTR_PW_PORT    GPIOC
#define PTR_PW_GPIO    GPIO_Pin_1
```

### 검토 결과 (Table 4 기준)

| 신호 | PORT | PIN | 실제 핀 | I/O Level | High sink/source | OD | PP | 판정 |
|---|---|---|---|---|---|---|---|---|
| **STP_CK** | GPIOB | Pin_1 | **PB1** | 표준 | ✅ HS | ✅ | ✅ | **정상** |
| **PTR_PW** | GPIOC | Pin_1 | **PC1** | FT | ❌ 없음 | ✅ True OD | ❌ 없음 | **문제** |

- **PB1 (STP_CK)**: High Sink/Source 완전 지원, Source/Sink 최대 10 mA, 현재 Input 용도와 무관하게 출력으로도 사용 가능
- **PC1 (PTR_PW)**: True Open Drain 전용, PMOS 없음 → High 출력 불가, PTR 전원 제어 용도에 부적합

### PTR_PW 해결 방안

```c
/* 변경 전 — 문제 */
#define PTR_PW_PORT    GPIOC
#define PTR_PW_GPIO    GPIO_Pin_1   // PC1: True OD, High 출력 불가

/* 변경 후 — 예시 (회로 확인 후 결정) */
#define PTR_PW_PORT    GPIOB
#define PTR_PW_GPIO    GPIO_Pin_0   // PB0: HS Push-Pull, 최대 10 mA
```

PB, PD, PC2~PC6 계열 중 회로상 여유 핀으로 변경 필요.

## PC1 내부 풀업 입력 가능 여부

### Table 4 입력 컬럼 확인

| 핀 | floating | wpu (내부 풀업) | Ext. interrupt |
|---|---|---|---|
| **PC1/I2C_SCL** | ✅ X | ❌ **없음** | ✅ X |
| PB1 (참고) | ✅ X | ✅ X | ✅ X |

**PC1은 내부 풀업 회로가 하드웨어적으로 존재하지 않는다.**

### 입력 모드별 동작

| 입력 모드 | PC1 실제 동작 |
|---|---|
| `GPIO_Mode_In_FL_No_IT` (Floating) | ✅ 정상 동작 |
| `GPIO_Mode_In_PU_No_IT` (내부 풀업) | ❌ 풀업 회로 없음 → Floating과 동일 |
| `GPIO_Mode_In_PU_IT` (내부 풀업 + 인터럽트) | ❌ 풀업 미동작, 핀 부유 |

소프트웨어에서 `GPIO_Mode_In_PU_No_IT`로 설정해도 라이브러리가 레지스터를 쓰긴 하지만,
하드웨어 풀업 회로가 없으므로 **실제로는 Floating Input과 동일하게 동작**.
외부 풀업 없이 핀이 부유 상태가 되면 노이즈에 의한 오동작 위험 있음.

### PC1을 Input으로 사용하려면

외부 Pull-up 저항 필수:

```
VDD ──[ 10kΩ ]── PC1 ── (입력 신호)
```

설정은 `GPIO_Mode_In_FL_No_IT` (Floating) 사용.
