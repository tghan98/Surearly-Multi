# 작업 로그 - 2026.04.27

## 1. LCD 애니메이션 및 시퀀스 구현
- **과사용 오류 애니메이션 (`LCD_SQ_ERR_OVER_USED`)**
    - 시퀀스: ALL OFF -> BOOK(500ms) -> ALL OFF -> NO(500ms) -> ALL OFF -> YES(500ms) -> ALL OFF -> DROP(500ms) -> 반복.
    - `DM_LCD_Stick_Check_App.c`에 구현 완료.
- **스틱 제거 오류 단계 (`LCD_SQ_ERR_STICK_REMOVE`)**
    - 로직: ALL OFF -> BOOK ON & DROP Blink 설정.
    - 설정 완료 후 상태 유지를 위해 `LCD_SQ_IDLE`로 전환.
- **스틱 실패 오류 단계 (`LCD_SQ_ERR_STICK_FAIL`)**
    - 로직: ALL OFF -> BOOK ON 설정.
- **결과 출력 단계**
    - `LCD_SQ_RESULT_YES`: ALL OFF -> YES ON 설정.
    - `LCD_SQ_RESULT_NO`: ALL OFF -> NO ON 설정.

## 2. 메인 시퀀스 로직 업데이트 (`DM_Main_Sq_App.c`)
- **사용 횟수 제한 가드레일 추가**
    - `MAIN_SQ_STICK_INSERT` 단계에서 `TestCompleteCount > 30` 조건 검사 추가.
    - 조건 만족 시 `LCD_SQ_ERR_OVER_USED` 애니메이션을 실행하고 `MAIN_SQ_ERROR_WAIT` 단계로 진입.
- **오류 대기 처리**
    - `MAIN_SQ_ERROR_WAIT` 단계에서 10초간 타이머를 작동시켜 애니메이션을 보여준 뒤, 절전 모드인 `MAIN_SQ_IDLE` (Halt)로 진입하도록 구현.

- **시스템 관리 변수 추가**

    - `gs_awResultBand_LowData[4]`: 결과 측정 상태의 Raw ADC 데이터 배열.
