### 2. 에러 관리 시스템 강화
- **Error Sequence 변수 추가**: 에러 발생 시점의 스텝을 추적하기 위한 `gs_bErrorSequence` 정적 전역 변수 및 Getter/Setter 추가.
- **에러 코드 확장**:
  - `ERROR_C_LINE_FAIL (0x06)`: C-Line 형성 실패 에러.
  - `ERROR_SAMPLE_LOAD_FAIL (0x07)`: 5분 내 샘플 감지 실패(타임아웃) 에러.
- **에러 처리 로직 수정**:
  - 샘플 감지 이후(`OVER_SAMPLE_CHECK` 단계부터) 스틱이 제거될 경우, 단순 제거가 아닌 `ERROR_STICK_FAIL`로 처리하도록 변경.

### 3. 메인 시퀀스 단계별 핸들러 구현 (`DM_Main_Sq_App.c`)
- **`MAIN_SQ_SAMPLE_LOAD_WAIT`**: 
  - 공스틱 대비 T/BT 비율을 모니터링하여 샘플 로딩 감지.
  - 5분 타임아웃 시 측정 데이터 저장 및 `ERROR_SAMPLE_LOAD_FAIL` 기록 후 슬립.
- **`MAIN_SQ_OVER_SAMPLE_CHECK`**:
  - 샘플 감지 5초 후 C-Line 급격 변화 체크를 통한 과유입(Over-flow) 판정.
- **`MAIN_SQ_LOW_SAMPLE_CHECK`**:
  - 샘플 감지 20초 후 C-Line 형성 여부를 체크하여 샘플 부족 판정.
- **`MAIN_SQ_REACTION_WAIT`**:
  - 이전 단계 시간을 포함하여 총 3분간의 반응 시간 대기 보장.
- **`MAIN_SQ_RESULT_SCAN`**:
  - C -> BC -> BT -> T 역순 측정 및 정규화(Normalization).
  - T/C 임계값 비교를 통한 YES/NO 최종 판정.
  - 결과를 `gs_awResult[]` 통합 배열에 저장 (Enum 사용).

### 4. 데이터 저장 시스템 및 종료 로직
- **`DM_App_Main_Sq_Save_Result_To_Rom()`**: 
  - 32바이트 데이터 패킹 인터페이스 구현.
  - 배치 순서: PWM(8B) -> Empty(8B) -> Result Low(8B) -> Result Values(6B) -> Dummy(2B).
  - 스틱 삽입 횟수(`Insert Count - 1`)를 인덱스로 사용하여 저장.
- **`MAIN_SQ_RESULT_OUT`**:
  - 테스트 완료 횟수 증가 및 EEPROM 저장.
  - 최종 데이터 ROM 기록.
  - 5분 대기 후 저전력 모드(IDLE) 진입.
- **`MAIN_SQ_ERROR_WAIT`**:
  - 에러 발생 시 코드 및 단계 EEPROM 저장.
  - 진단용 광학 데이터 ROM 기록.
  - 2분 대기 후 저전력 모드(IDLE) 진입.

### 7. 소스 코드 최적화 및 안정화 (Refactoring)
- **데이터 관리 구조 개선**:
  - `DM_Optic_Handle_App` 모듈에서 관리하던 광학 데이터 배열(`gs_awInitialStickPtr`, `gs_awEmptyStickPtr`)을 제거하고, 메인 시퀀스(`DM_Main_Sq_App`)로 통합 관리하도록 리팩토링.
  - 이를 통해 모듈 간 중복 데이터 보관을 없애고 RAM 사용량을 최적화함.
- **인터페이스 최적화**:
  - `DM_App_Optic_MeasureInitialStick()`, `DM_App_Optic_MeasureEmptyPTR()` 등 하드웨어 조작 함수들이 내부 static 변수를 사용하지 않고, 호출자로부터 버퍼 포인터를 전달받아 직접 기록하도록 변경.
- **버그 수정 (Critical Index Underflow)**:
  - ROM 저장 함수(`DM_App_Rom_Save_CurrentResult`)가 1-based count 대신 0-based index를 직접 받도록 수정하여, 첫 번째 테스트 시 발생할 수 있는 인덱스 언더플로우 및 저장 누락 문제를 해결함.
- **헤더 및 선언 정리**: 중복 정의된 프로토타입과 사용되지 않는 Dead Code(구형 Getter/Setter)를 전수 조사하여 삭제함으로써 빌드 안정성을 확보함.

---
**기타 사항:** 모든 전역 변수는 `static`으로 캡슐화되었으며, 명시적인 인터페이스 함수를 통해서만 데이터 접근이 가능하도록 구현됨.
