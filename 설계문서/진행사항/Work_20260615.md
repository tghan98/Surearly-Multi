## 1. LED 회로 조립 역방향 대응 펌웨어 수정

### 배경

하드웨어 조립 시 LED 애노드/캐소드 연결이 설계와 반대로 조립됨.  
조립된 상태 그대로 동작하도록 펌웨어 수정.

### 회로 구조 비교

| 핀 | 설계 의도 | 실제 조립 |
|----|-----------|-----------|
| PB2 (TIM2_CH2 PWM) | LED 애노드 (소스) | LED 캐소드 (싱크) |
| PB4 (LED1_GPIO) | LED1 캐소드 (싱크) | LED1 애노드 (소스) |
| PB3 (LED2_GPIO) | LED2 캐소드 (싱크) | LED2 애노드 (소스) |

```
[설계 의도]
PWM(PB2) ─── R(51Ω) ──┬── LED1 ── LED1_GPIO(PB4) ── GND
                        └── LED2 ── LED2_GPIO(PB3) ── GND

[실제 조립]
GND ── LED1_GPIO(PB4) ── LED1 ──┬── R(51Ω) ─── PWM(PB2)
       LED2_GPIO(PB3) ── LED2 ──┘
```

### 수정 파일

`USER/Drive/DM_HW_Drv.c`

---

### 수정 1 — GPIO 초기 상태 (`DM_HW_Drv_GPIO_Init`, 줄 71-72)

PB4/PB3가 애노드로 변경 → 기본값 LOW (LED OFF)

```c
/* 변경 전: 캐소드 제어 (High = LED OFF) */
GPIO_Init(LED1_GPIO_PORT, LED1_GPIO_PIN, GPIO_Mode_Out_PP_High_Fast);
GPIO_Init(LED2_GPIO_PORT, LED2_GPIO_PIN, GPIO_Mode_Out_PP_High_Fast);

/* 변경 후: 애노드 제어 (Low = LED OFF) */
GPIO_Init(LED1_GPIO_PORT, LED1_GPIO_PIN, GPIO_Mode_Out_PP_Low_Fast);
GPIO_Init(LED2_GPIO_PORT, LED2_GPIO_PIN, GPIO_Mode_Out_PP_Low_Fast);
```

---

### 수정 2 — PWM 극성 반전 (`DM_HW_Drv_LED_TIM2_Init`, 줄 114)

PB2가 캐소드로 변경 → PWM LOW일 때 전류 흐름 → 극성 반전

```c
/* 변경 전: 애노드 구동 (High = 전류 흐름) */
TIM2_OCPolarity_High,

/* 변경 후: 캐소드 구동 (Low = 전류 흐름) */
TIM2_OCPolarity_Low,
```

> PWM1 모드 + `OCPolarity_Low` 적용 시:  
> CCR=0 → PB2 항상 HIGH → LED OFF, CCR=399 → PB2 항상 LOW → LED 100% ON  
> Duty 값(0~399)의 의미는 기존과 동일하게 유지됨

---

### 수정 3 — LED ON/OFF 제어 로직 반전 (`DM_HW_Drv_LED_Control`, 줄 139-158)

PB4/PB3가 애노드 → HIGH = ON, LOW = OFF 로 변경

```c
/* 변경 전: Low Active (캐소드 싱크) */
// ENABLE:
GPIO_SetBits(LED2_GPIO_PORT, LED2_GPIO_PIN);    /* LED2 OFF (High) */
GPIO_ResetBits(LED1_GPIO_PORT, LED1_GPIO_PIN);  /* LED1 ON  (Low)  */
// DISABLE:
GPIO_SetBits(LED1_GPIO_PORT, LED1_GPIO_PIN);    /* LED1 OFF (High) */

/* 변경 후: High Active (애노드 소스) */
// ENABLE:
GPIO_ResetBits(LED2_GPIO_PORT, LED2_GPIO_PIN);  /* LED2 OFF (Low)  */
GPIO_SetBits(LED1_GPIO_PORT, LED1_GPIO_PIN);    /* LED1 ON  (High) */
// DISABLE:
GPIO_ResetBits(LED1_GPIO_PORT, LED1_GPIO_PIN);  /* LED1 OFF (Low)  */
```

---

### 수정 4 — PWM 정지 시 핀 상태 (`DM_HW_Drv_LED_Stop`, 줄 224)

PWM 정지 후 PB2(캐소드)를 HIGH로 유지 → LED OFF 보장

```c
/* 변경 전: 핀을 LOW로 구동 */
GPIO_WriteBit(LED_PWM_GPIO_PORT, LED_PWM_GPIO_PIN, RESET);

/* 변경 후: 캐소드를 HIGH로 구동 → LED OFF */
GPIO_WriteBit(LED_PWM_GPIO_PORT, LED_PWM_GPIO_PIN, SET);
```

---

### 수정 5 — Sleep 진입 전처리 (`DM_HW_Drv_Power_PrepareSleep`, 줄 456-457)

Sleep 진입 전 PB4/PB3(애노드)를 LOW로 → LED OFF 보장

```c
/* 변경 전 */
GPIO_SetBits(LED1_GPIO_PORT, LED1_GPIO_PIN);
GPIO_SetBits(LED2_GPIO_PORT, LED2_GPIO_PIN);

/* 변경 후 */
GPIO_ResetBits(LED1_GPIO_PORT, LED1_GPIO_PIN);
GPIO_ResetBits(LED2_GPIO_PORT, LED2_GPIO_PIN);
```
