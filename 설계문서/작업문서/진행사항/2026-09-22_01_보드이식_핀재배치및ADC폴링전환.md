# 2026-09-22_01_보드이식_핀재배치및ADC폴링전환

## 한 줄 요약

> v1.1 보드의 실제 핀맵에 맞춰 LED/LCD 연결과 광학 측정의 기본 구조를 변경하고, IAR 빌드까지 확인했습니다.

## 1. 뭘 하려던 거였나 (배경)

기존 펌웨어는 v2.1 보드 기준으로 작성되어 LED와 LCD가 실제 v1.1 보드의 핀과 다릅니다.

또한 기존 코드는 LED 밝기를 PWM으로 조절하지만, v1.1 보드에는 LED 밝기를 조절할 PWM 회로가 없습니다. 따라서 LED를 켠 뒤 얼마나 기다렸다가 ADC 값을 읽을지로 측정값을 조절하는 구조로 변경해야 합니다.

이번 작업에서는 먼저 핀 연결과 측정 구조를 v1.1 보드에 맞추고, 코드가 정상적으로 빌드되는지 확인했습니다.

## 2. 뭘 했나

### 2.1 v1.1 보드 핀맵 반영

LED1을 PB4, LED2를 PB3, LCD COM을 PB2로 변경했습니다. LED는 Push-Pull 출력으로 설정하고 High를 소등 상태로 사용하도록 변경했습니다.

### 2.2 PWM 및 PTR 전원 제어 제거

v1.1 보드에는 LED PWM 핀과 PTR 전원 제어 핀이 없으므로 TIM2 LED PWM 초기화와 관련 함수를 제거했습니다. PB3은 PTR 전원이 아니라 실제 LED2 핀이므로 PTR 전원 제어도 제거했습니다.

### 2.3 LED 점등시간 기반 측정 구조 적용

광학 측정 순서를 다음과 같이 변경했습니다.

LED 켜기 → 지정된 on-time 대기 → ADC 20회 측정 → LED 끄기 → 10ms 회복 대기

기존의 측정 전 10ms 안정화 대기는 제거하고, ADC 결과를 정렬한 뒤 중앙 14개를 합산하는 방식은 유지했습니다.

### 2.4 ADC 변환 방식 단축

ADC 샘플링 시간을 384사이클에서 16사이클로 변경했습니다. ADC 완료 대기는 EOC 인터럽트와 `wfi()` 방식에서 EOC 플래그 폴링 방식으로 변경했습니다.

현재 `ADC_READ_TIME_US`와 `DELAY_US_CAL`은 실제 보드 측정 전의 임시값입니다.

## 4. 걸린 것 / 남은 것

- `DELAY_US_CAL`은 실제 LED on-time 측정으로 보정해야 합니다.
- `ADC_READ_TIME_US`는 ADC 실제 변환시간을 측정한 뒤 갱신해야 합니다.
- `OPTIC_ONTIME_MAX`, `OPTIC_ONTIME_X1`, `OPTIC_ONTIME_X2`는 아직 임시값입니다.
- 2점 선형 보간 튜닝은 아직 구현하지 않았습니다.
- 실제 보드 동작과 광학 ADC 값은 아직 검증하지 않았습니다.
- 빌드 과정에서 변경된 `OVULATION_MULTI_New.dep`는 자동 생성 변경으로 판단해 커밋하지 않습니다.
