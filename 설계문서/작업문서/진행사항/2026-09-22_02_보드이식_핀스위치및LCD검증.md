# 2026-09-22_02_보드이식_핀스위치및LCD검증

## 한 줄 요약

> 디버거 레지스터로 v1.1 보드의 LED 핀과 스틱 스위치를 확인하고, 광학 판정을 우회한 LCD 시퀀스가 정상 동작하는 것을 확인했습니다.

## 1. 뭘 하려던 거였나 (배경)

이번 단계의 목적은 광학 측정값을 검증하는 것이 아니라, 보드에 연결된 기본 입출력과 LCD 경로를 먼저 확인하는 것이었습니다.

광학용 LED는 케이스 안쪽을 향하고 있어 육안으로 점등 여부를 판단하기 어렵습니다. 따라서 디버거의 GPIOB 레지스터를 사용해 MCU가 실행 중인지, 핀 방향과 출력 상태가 맞는지, 스틱 스위치 입력이 변하는지를 확인했습니다.

## 2. 뭘 했나

### 2.1 디버거 레지스터로 LED 핀 검증

IAR 디버거에서 `PB_DDR`, `PB_CR1`, `PB_CR2`, `PB_ODR`, `PB_IDR`를 확인했습니다. PB4와 PB3은 출력·Push-Pull·Fast 설정이었고, 스틱을 뺀 상태에서 PB4는 Low, PB3은 High였습니다.

### 2.2 스틱 감지 입력 검증

스틱을 뺀 상태에서 PB1 입력은 High였고, 스틱을 삽입하자 Low로 바뀌었습니다. 동시에 PB3 출력도 High에서 Low로 바뀌어 PB1이 실제 스틱 감지 스위치 입력임을 확인했습니다.

### 2.3 LCD 시퀀스 검증

광학 측정이 LCD 테스트를 막지 않도록 `_DEBUG_LCD_SEQ_ONLY`를 1로 설정하고, IDLE에서 기계식 스틱 감지로 깨어난 뒤 광학 스틱 판정을 건너뛰고 `STICK_INSERT` LCD 시퀀스로 전이하도록 변경했습니다.

스틱을 삽입한 뒤 LCD가 깜빡이고 아이콘을 순서대로 표시한 후 빈 화면으로 돌아오는 동작을 확인했습니다. 이는 LCD COM/SEG 핀, TIM4 인터럽트, LCD 위상 반전 갱신 경로가 동작한다는 뜻입니다.

## 3. 확인된 것 / 잘 된 것

- [x] MCU 실행 및 디버거 중단 위치 확인
- [x] PB4/PB3 출력 방향 확인
- [x] PB4/PB3 Push-Pull 설정 확인
- [x] 스틱 미삽입 상태의 PB1 High 확인
- [x] 스틱 삽입 상태의 PB1 Low 확인
- [x] 스틱 삽입에 따른 PB3 출력 변화 확인
- [x] LCD 깜빡임 및 아이콘 순차 표시 확인
- [x] LCD 시퀀스 종료 후 빈 화면 전환 확인
- [ ] 광학 ADC 값 및 실제 측정 결과 확인
- [ ] 정상 운용 모드에서 전체 광학 시퀀스 확인

## 4. 걸린 것 / 남은 것

- `_DEBUG_LCD_SEQ_ONLY`는 LCD 검증을 위해 현재 1로 유지하고 있습니다.
- 정상 광학 측정을 시작할 때는 `_DEBUG_LCD_SEQ_ONLY`를 0으로 되돌려야 합니다.
- `DELAY_US_CAL`은 실제 on-time을 측정해 보정해야 합니다.
- `ADC_READ_TIME_US`는 16사이클 ADC의 실제 변환시간을 재측정해 갱신해야 합니다.
- 현재 LED는 케이스 조립 상태에서 육안 확인이 어려우므로 GPIO 레지스터 또는 PTR ADC 값으로 판단해야 합니다.
