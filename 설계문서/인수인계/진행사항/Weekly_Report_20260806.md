## 2. PTR 광센서 ADC 이상 조사 → 센서 로트 불량 판정 (7/31)

- 특정 보드에서 ADC 값이 정상 대비 6.7~9배 낮게 나오는 현상 발견, 센서 교체 스왑 테스트로 **보드/펌웨어 문제가 아닌 부품(포토트랜지스터) 로트 불량**으로 확정.
- 데이터시트 스펙(IC(ON) 개체차 최대 ~2.7배) 대비 실측 편차가 훨씬 커 불량 판정 근거 확보, 문제 센서 교체 후 테스트 기기 5대 정상 동작 확인.
- 후속 조치: 입고검사(수입검사) 기준 수립 필요, Everlight/디지키에 Bin(랭크) 지정 구매 가능 여부 확인 필요.

## 3. 스틱 삽입 스위치(STP_CK) 오동작 근본 해결 (7/31)

- 기구적 접점 문제로 스틱이 삽입된 상태에서도 순간적으로 REMOVE로 오판되는 문제를, 기존 GPIO 디바운스 방식 대신 **광학 센서(OPTIC_CH_3) 기반 판정**으로 전환.
- STP_CK 스위치는 Halt wake-up 트리거 전용으로 역할 축소, 실질적 삽입/제거 판정은 전부 옵틱 측정 기반.
- Wake-up 직후 확인 로직, 캐시 우회(항상 최신 측정값 사용) 등 세부 보완 포함. **실물 보드 검증 완료, 정상 동작 확인.**
- 부가 수정: 슬립 진입 시 LCD DROP 아이콘 리셋 누락 버그, 초기 측정값 정상범위 검증(불량/이물질 스크리닝) 로직 추가.

## 4. 반응시간 타이밍 정밀도 확보 (7/31~8/4)

- 5분 대기(Sample_Load_Wait)가 실제로는 5분 37초로 부정확했던 문제를 단계적으로 원인 규명 및 수정.
- 대기 루프를 "반복횟수 카운트" 대신 `GetSystemTick()` 실측 시간 기준으로 변경, ADC 변환시간 미반영 오차 보정, `GetSystemTick()` 나눗셈 연산 오버헤드 제거, TIM4 클럭 실측 기반 재보정(ARR 155→144) 등을 거쳐 **5:37 → 5:02**까지 개선.
- 8/4일 측정시간 단축(24ms화, 하단 5절) 이후 타이밍이 재악화(5:35)되어 재보정 진행, TIM4 ARR 144→149·ADC_READ_TIME_US 200→220으로 최종 **5:06**(목표 대비 +6초, 약 2%)으로 수렴. 잔여오차는 사용자 확인 하에 수용 결정.

## 5. 측정 루프 성능 개선 및 재구성 (8/4)

- `DM_App_Optic_Measure()` 측정시간을 200ms → **24ms**로 약 8배 단축(불필요한 RC 안정화 대기 반복 제거, LED 회복시간은 배터리 보호를 위해 유지).
- 측정 단축으로 인해 급증한 ADC 호출수(5분간 약 95,000회)를 스틱 체크 폴링 주기 완화(250ms 단위 재구성)로 약 18,000회 수준으로 정상화.
- LED/배터리 회로 전류 분석(LED 실동작 전류 1~2mA, CR1632 내부저항 기반 전압강하 계산) 수행 — 오실로스코프 실측은 미완료로 남음.
- 코드 사이즈 최적화 4개 항목 시도 후 실측 결과 오히려 사이즈 증가(+3~14바이트)로 확인되어 **전체 원복**.

## 6. 신규 LED(LTST-C193KGKT-5A) 검토 및 Bin 지정 구매 결정 (8/4)

- 기존 LED 대비 스펙 비교 시 테스트 전류 조건(20mA vs 5mA) 차이로 단순 수치 비교가 무효함을 확인, 회로 실동작 전류(~1~2mA) 기준으로 재계산.
- 저항값 조정으로는 Bin 편차(최대 약 4배)가 줄지 않음을 수식으로 검증, **VF Bin: E2, IV Bin: K** 지정 구매로 결정.

## 7. USART 서비스 기능 및 문서화 (8/4~8/5)

- 서비스/수리용 테스트 카운트 리셋 명령(`'R'`/`'r'`) 신규 추가.
- RawDump(EEPROM 원시 덤프) 응답에 펌웨어 버전/LOT 헤더(21바이트) 추가 — 총 269바이트.
- PC용 GUI 개발 지원을 위해 `EEPROM_UART.md` 신규 작성(EEPROM 구조 맵, USART 프로토콜, 바이트 오프셋 테이블 전체 정리).
- `CodeingCompleteReport.md`를 실제 코드 기준으로 최신화(스틱 감지 방식 서술 정정, 스틱 유효성 검증 단계 반영).

## 8. 데이터 저장 버그 2건 수정 (8/5)

- **C-Line Fail 시 T/C Intensity 미저장 버그**: 계산값 저장이 C-Line 유효성 체크의 `return`보다 뒤에 있어 이전 테스트 값이 그대로 저장되던 문제 수정(저장 순서 변경).
- **Wake-up 직후 잔존 데이터 문제**: 이번 사이클이 초기 단계에서 실패해도 이전 테스트의 PWM/Band/Intensity 값이 남아있던 문제 — 스텝 진입 시 관련 값 전체 리셋 로직 추가.
