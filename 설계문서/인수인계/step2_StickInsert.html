② 스틱 확인 · 초기 점검 — 세부 흐름도

전체 흐름도의 2번 단계를 자세히 풀어본 그림입니다. 스틱이 꽂힌 직후, 검사를 시작해도 되는지 확인하고 센서를 보정합니다.

정상 진행 단계 완료(다음 단계로) 오류 처리 정상 흐름 오류 발생 경로

🔎 단계별 자세히 보기

1
📥 삽입 횟수 갱신 · 사용 횟수 확인

기기 내부(EEPROM)에 저장된 스틱 삽입 횟수와 그동안 완료한 테스트 횟수를 불러와 삽입 횟수를 1 늘려 다시 저장합니다. 완료한 테스트가 30회를 넘었으면 더 이상 사용할 수 없어 오류로 처리합니다.

⚠ 사용 횟수 30회 이상 → 오류 처리
2
📡 초기 밝기 측정

스틱이 진짜 정상 제품인지 확인하기 위해, 4개 센서 채널을 각각 2단계 밝기(50%, 100%)로 총 8번 측정해서 값이 정상 범위 안에 있는지 봅니다.

⚠ 도중 스틱 빠짐 → 오류 처리
⚠ 측정값 범위 이탈(불량 의심) → 오류 처리
3
🎯 센서 밝기 자동 보정

스틱/센서 개체차를 보정하기 위해, 채널별로 목표 밝기가 나올 때까지 LED 세기를 자동으로 조절합니다(최대 5회 시도).

⚠ 도중 스틱 빠짐 → 오류 처리
⚠ 5회 안에 목표 도달 실패 → 오류 처리
4
📏 빈 스틱(기준) 값 측정

보정된 밝기로, 아직 반응이 시작되기 전의 "기준값"을 4개 채널 모두 측정해 저장합니다. 이후 모든 판정은 이 기준값과 비교해서 이뤄집니다.

⚠ 도중 스틱 빠짐 → 오류 처리
5
⏳ 삽입 안내 화면 종료 대기

화면에 나오는 "스틱을 삽입하세요" 안내 애니메이션이 끝날 때까지, 스틱이 계속 꽂혀 있는지 확인하며 기다립니다.

⚠ 도중 스틱 빠짐 → 오류 처리
✓
완료

위 과정을 모두 통과하면 ③ 샘플(소변) 투입 대기 단계로 넘어갑니다.

!
🚫 이 단계에서 발생 가능한 오류

사용 횟수 초과 · 스틱 빠짐 · 스틱/센서 불량(범위 이탈) · 밝기 보정 실패 — 어떤 원인이든 처리 방식은 동일합니다: 원인 기록 → 오류 메시지 약 2분 표시 → 대기 모드로 복귀. (공통 절차의 자세한 설명은 전체 흐름도 문서 참고)
