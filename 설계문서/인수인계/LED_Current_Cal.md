## 1. 하드웨어 구성

### 핀 정의

| 핀 이름 | GPIO | 역할 |
|---------|------|------|
| LED_PWM_GPIO_PIN | PB2 | PWM 출력 (High측, 소스) |
| LED1_GPIO_PIN | PB4 | LED1 ON/OFF 제어 (Low측, 싱크) |
| LED2_GPIO_PIN | PB3 | LED2 ON/OFF 제어 (Low측, 싱크) |

### 회로 구조

```
VCC(2.5V)
    │
PWM_PIN(PB2) ─── R(51Ω) ──┬── LED1(LTW-C191KGKT) ── LED1_GPIO(PB4) ── GND
                            └── LED2(LTW-C191KGKT) ── LED2_GPIO(PB3) ── GND
```

- PWM_PIN(PB2) : **High측 구동** (PWM 출력)
- LED1/LED2_GPIO_PIN : **Low측 싱크** (LOW 설정 시 해당 LED 점등)
- 두 LED가 51Ω 저항 **1개를 공유**하는 병렬 구조

## 4. 전류 계산 공식

### 기본 공식

```
I_peak = (V_drive - Vf) / R
       = (2.3V - Vf) / 51Ω

I_avg  = I_peak × Duty Cycle (%)
```

### LED 점등 조건별 전류

| 조건 | 전류 계산 |
|------|-----------|
| LED 1개만 점등 | I = (V_drive - Vf) / 51Ω |
| LED 2개 동시 점등 | I_total = (V_drive - Vf) / 51Ω, 각 LED = I_total / 2 |

## 5. 케이스별 전류 계산 결과

### Case A : Vf = 2.0V (Green LED 계열 가정)

| PWM 조건 | LED 점등 수 | I_peak (ON시) | I_avg |
|----------|------------|--------------|-------|
| **PWM 99%** | LED 1개 | 5.9mA | **5.84mA** |
| **PWM 10%** | LED 1개 | 5.9mA | **0.59mA** |
| **PWM 99%** | LED 2개 동시 | 각 2.94mA | **각 2.91mA** |
| **PWM 10%** | LED 2개 동시 | 각 2.94mA | **각 0.29mA** |

> 계산: I_peak = (2.3 - 2.0) / 51 = 0.3 / 51 = **5.88mA ≈ 5.9mA**

---

### Case B : Vf = 2.4V (White LED 계열 가정)

| PWM 조건 | LED 점등 수 | I_peak (ON시) | I_avg |
|----------|------------|--------------|-------|
| **PWM 99%** | LED 1개 | ≈ 2.0mA | **≈ 1.98mA** |
| **PWM 10%** | LED 1개 | ≈ 2.0mA | **≈ 0.20mA** |
| **PWM 99%** | LED 2개 동시 | 각 ≈ 1.0mA | **각 ≈ 0.99mA** |
| **PWM 10%** | LED 2개 동시 | 각 ≈ 1.0mA | **각 ≈ 0.10mA** |

> 계산: I_peak = (2.5 - 2.4) / 51 = 0.1 / 51 = **≈ 2.0mA** (VCC 기준 사용)  
> 코인셀 설계에 적합한 전류 — 배터리 수명 최적화에 유리

## 6. 저항 소비전력 검토

| Vf 가정 | I_peak | P_resistor = I² × R |
|---------|--------|---------------------|
| Vf = 2.0V | 5.9mA | (5.9×10⁻³)² × 51 = **1.78mW** |
| Vf = 2.4V | 2.0mA | (2.0×10⁻³)² × 51 = **0.20mW** |

→ 두 경우 모두 저항 소비전력 문제 없음

## 9. 결론 및 확인 사항

1. **LTW-C191KGKT 데이터시트에서 동작 전류 기준 Vf 값 확인 필수**
2. VCC = 2.5V 제약 조건상 **Vf < 2.3V** 이어야 정상 점등 가능 (GPIO 출력 전압 고려)
3. LED 2개 동시 점등 시 51Ω 저항 공유 → **각 LED 전류가 절반으로 감소** 주의
4. 정확한 계산식:

```
I_peak [mA] = (2300 - Vf[mV]) / 51
I_avg  [mA] = I_peak × (Duty_Cycle / 100)
```
