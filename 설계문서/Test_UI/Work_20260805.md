## 1. UI 레이아웃 정리 — 통신 스펙을 포트 연결 패널로 통합

- 기존에 별도 패널로 분리돼 있던 "통신 스펙"(Baud/Data Bits/Stop Bits/Parity 4칸 그리드)을 제거.
- 대신 "포트 연결" 패널 상단에 한 줄짜리 요약 텍스트(`Baud Rate 9600 · Data Bits 8 · Stop Bits 1 · Parity None`, `.spec-mini`)로 축소 삽입.
- 패널 순서를 포트 연결 → 서비스 명령 → 터미널 순으로 재배치(포트 연결을 최상단으로 이동).
- 더 이상 쓰이지 않는 `.spec-grid`/`.spec-item` CSS 삭제.

## 2. RawDump 데이터 출력 양식을 `EEPROM_UART.md` / `Multi_Data.png` 기준으로 재구성

- 기존 파서(`parseRawDump`)의 바이트 오프셋(헤더 21 + 상태 8 + 초기스틱 16 + 레코드 7×32 = 269B)이 `EEPROM_UART.md` §2-5 오프셋 테이블과 이미 일치함을 재확인.
- 초기 스틱 PTR 채널 라벨을 `CH0~CH3` 숫자 표기 → `T/BT/BC/C` 밴드 명칭으로 변경(`Multi_Data.png`의 컬럼명 및 `BAND_TYPE_t` enum 순서와 일치).
- 결과 화면을 카드형(`dump-grid`/`dump-item`) 대신 이미지와 동일한 "필드/데이터" 행 구조의 실제 `<table>` 4개로 재구성:
  1. Firmware Ver. / Real Firmware Ver. / LOT. Upper / LOT. Lower (문자열)
  2. Insert Count / Test Complete Count / Error Step / Error Code
  3. T/BT/BC/C 각각의 Duty 50%·100% (초기 스틱 PTR)
  4. 결과 레코드 7행: PWM CH1-4, ET/EBT/EBC/EC, RT/RBT/RBC/RC, T/C Intensity, Yes(1)/No(0)
- Error Code를 16진수 대신 `ERROR_CODE_MAP`(`EEPROM_UART.md` §1-4 기준)으로 매핑한 문자열로 표시(`ERROR NONE` 등).
- 이미지에 표기된 유효 범위(`900 < Duty 50% < 2100`, `1800 < Duty 100% < 4200`)를 안내 문구로 추가하고, 범위를 벗어난 값은 빨간색(`.value-warn`)으로 강조.
- 레코드 표의 `Dummy` 컬럼은 이미지 양식에 없어 제거, 슬롯 번호는 이미지처럼 1~7로 표시(기존 `★최신추정` 텍스트 라벨은 제거하고 최신 슬롯 배경 강조만 유지).

## 3. 데이터 미수신 시에도 표를 항상 표시하도록 변경

- 기존에는 RawDump 버튼을 눌러 269바이트를 실제로 수신해야만 표가 DOM에 생성되고, 그 전에는 안내 문구(placeholder)만 표시되던 구조였음.
- `emptyRawDumpData()`를 추가해 모든 필드를 빈 문자열/`-`로 채운 더미 데이터를 만들고, 페이지 로드 시 `renderRawDumpTable(emptyRawDumpData())`을 호출해 4개 표가 처음부터 항상 화면에 그려지도록 변경.
- 렌더링 로직을 파싱(`renderRawDump`)과 표 생성(`renderRawDumpTable` → `buildRawDumpTablesHtml`)으로 분리.
- `isOutOfRange`/`describeErrorCode`가 숫자가 아닌 더미 값(`-`, `null`)을 받아도 안전하게 동작하도록 가드 추가.

## 4. 줄바꿈(line ending) 전송 버그 발견 및 수정

- 리포트: `<option value="\n">` 등 HTML 속성값 안의 `\n`/`\r\n`은 자바스크립트 이스케이프로 해석되지 않고 **리터럴 백슬래시 문자 그대로** `lineEnding.value`에 들어가는 버그를 발견 — 즉 CR(0x0D)/LF(0x0A) 대신 backslash+r/n 문자(0x5C, 0x72/0x6E)가 실제로 전송되고 있었음.
- 옵션 값을 식별자(`none`/`lf`/`crlf`/`cr`)로 바꾸고, JS의 `LINE_ENDINGS` 맵 + `getLineEnding()` 헬퍼에서 실제 이스케이프 문자로 변환하도록 수정.
- `sendData()`, `btnReset`, `btnRawDump` 핸들러 3곳 모두 `getLineEnding()`을 통해 값을 가져오도록 통일.

## 5. CSV 저장 / PDF 출력 버튼 추가

- 서비스 명령 패널에 `CSV로 저장`, `PDF로 출력` 버튼 추가. RawDump를 성공적으로 읽어와 파싱하기 전까지는 비활성화.
- `renderRawDump(bytes)`에서 파싱된 데이터를 `lastRawDumpData`에 저장하고, 파싱 성공 시에만 두 버튼을 활성화.
- 표 HTML 생성 로직을 `buildRawDumpTablesHtml(d)`로 공용화해 화면 표시와 PDF 출력에서 재사용.
- **CSV**: `buildRawDumpCsv(d)`로 4개 표를 CSV 텍스트로 변환 후 Blob(UTF-8 BOM 포함, 엑셀 한글 깨짐 방지)으로 다운로드. 파일명 `RawDump_YYYYMMDD_HHMMSS.csv`.
- **PDF**: 새 창(`window.open`)에 동일한 표를 인쇄용 스타일로 렌더링한 뒤 `window.print()` 호출 — 브라우저 인쇄 대화상자에서 "PDF로 저장"을 선택하는 방식(외부 라이브러리 없이 브라우저 기본 기능만 사용).
