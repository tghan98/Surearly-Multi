개발용 — 데이터 EEPROM 전체를 지우고 기기를 재시작합니다
리셋: 'R'/'r' + Enter → EEPROM/RAM의 TestCompleteCount 초기화. RawDump: 'M'/'m' + Enter → 249바이트(레코드 6개, QC 기준값 포함) 응답을 자동 파싱합니다. 구형 269·273바이트도 지원합니다. 레코드는 최신순으로 옵니다. QC 세션 초기화: 'Q'/'q' + Enter → 데이터 EEPROM 전체 초기화 후 OK 응답, 이어서 기기 재시작. 오클릭 방지를 위해 두 번 눌러야 전송됩니다. (개발용)
